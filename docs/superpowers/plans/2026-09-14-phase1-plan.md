# Phase 1 Plan — Working MVP

Goal: a compiling, runnable `LocalMusic.app` that downloads audio from a URL with live progress, files it under `~/Music/LocalMusic`, indexes it, plays it, and reveals it in Finder.

Order of work (each step compiles before the next):

1. Scaffolding: `Package.swift`, `project.yml`, `Makefile`, `Scripts/build.sh`, `Scripts/test.sh`, `Info.plist`, `.gitignore`.
2. Utilities: `FilenameSanitizer`, `PathGuard` (root confinement), `Logger`, `ByteFormatter`, `DurationFormatter`, `URLValidator`.
3. Models: `TrackRecord`, `DownloadJob` + `DownloadState`, `DownloadProgress`, `ToolInfo`, `AppSettings` (UserDefaults-backed), `LocalMusicError`.
4. Services: `ProcessRunner`, `ToolLocator` (+ version probe, brew update check), `YTDLPService` (probe URL / expand playlist / download with progress), `YTDLPProgressParser`, `YTDLPErrorClassifier`, `FFmpegService` (probe only in Phase 1), `FileOrganizer`, `LibraryScanner` (AVFoundation metadata), `LibraryStore` (Core Data), `PlaybackService`, `MockDownloader`.
5. Tests for: sanitizer, organizer paths, progress parser, URL validation, error classifier, path guard.
6. App: `LocalMusicApp`, `AppEnvironment` (DI container), `DownloadManager`, `LibraryViewModel`, `ContentView` (split view), `SidebarView`, `SongsView` (Table + context menu), `DownloadsView` (URL bar, dependency banner, playlist preview sheet, queue rows), `NowPlayingBar`, `SettingsView` (Downloads, Advanced), menu commands.
7. Build, run, download a real URL, verify file placement, playback, Finder reveal.
